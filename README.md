## 第一次使用，先看登录位置

共享账号只用于 App Store 下载或更新应用。打开 App Store，点右上角头像，在商店里切换账号。不要到手机“设置”顶部登录，也不要登录 iCloud 或“查找”。

下载完成后退出共享账号，换回自己的账号。不要修改共享账号的密码、手机号、地区和付款资料。遇到验证码、账号锁定或要求补充个人资料时，先停下来，把完整提示发给站内联系入口。

应用是否上架，要看对应地区的商店页面。下载到应用，也不代表它自带订阅、节点或其他服务；涉及付款、注册资格的要求，需要单独确认。

## 几个常见问题

**登录失败，要一直换账号试吗？**

先区分是密码错误、账号锁定，还是网络连接问题。连续重试未必有用。[登录失败排查](https://52id.org/articles/shared-apple-id-login-failed.html) 按提示分别说明了处理方式。

**更新应用时，为什么又要原来的账号？**

应用的获取记录和下载时使用的账号有关。换了商店账号，不一定能直接更新以前安装的应用。先看 [更新时要求原账号的说明](https://52id.org/articles/app-update-original-apple-id.html)，别急着卸载，避免丢掉应用里的本地数据。

**小火箭下载好了，为什么还不能用？**

Shadowrocket 是客户端，下载和后续的网络服务是两回事。应用获取方式、商店地区和使用边界整理在 [小火箭下载说明](https://52id.org/articles/shadowrocket-download-guide.html)。

其他问题可以从 [知识中心](https://52id.org/articles/) 找对应文章，或者看 [本站使用说明](https://52id.org/guide/site-instructions.html)。

## 这个仓库怎样更新

GitHub Actions 计划每天北京时间 00:00 运行，也支持手动执行。定时任务可能排队，实际读取时间以上面的记录为准。某个地区请求失败时，本次任务会报错，保留上次发布内容，不会用占位数据覆盖。

自动任务只刷新接口统计和读取时间，正文由人工维护，不会每天自动拼文章。每天有一次提交，也不代表全部账号都换过密码或重新检测过。

仓库只保存汇总数字，不收录完整账号、密码或原始接口响应。[机器可读统计](data/latest.json) · [维护方法](MAINTENANCE.md)
